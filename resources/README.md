## 收录规则

1. 先查许可证、体积和最后更新时间。
2. 超过 50 MB 的仓库不复制、不做 submodule；用脚本按需下载。
3. 外部内容统一放 `external/`，该目录已被 `.gitignore` 忽略。
4. 每个资源都要写清：来源、许可证、引用方式、最小用法。
5. 不在公开作品集里放未授权数据；只放脚本、衍生图和来源说明。
